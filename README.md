# Mbolo

Mbolo est une plateforme moderne et sécurisée de rencontres et de connexions
authentiques, conçue initialement pour le Gabon et l'Afrique centrale.

> Nom de code provisoire : Mbolo

## Objectifs

- proposer une expérience de rencontre adaptée aux réalités gabonaises ;
- lutter contre les faux profils, le harcèlement et les escroqueries ;
- protéger la confidentialité et la localisation des utilisateurs ;
- appliquer les principes Secure by Design et Privacy by Design ;
- respecter les exigences applicables en matière de protection des données ;
- construire une architecture Web puis mobile maintenable et évolutive.
