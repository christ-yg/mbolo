# Registres de preuves — lots 50 à 69

Ces modèles constituent le socle de preuves opérationnelles de Mbolo. Ils ne doivent contenir ni mot de passe, ni jeton, ni clé privée, ni contenu de conversation, ni média privé.

## Règles d’utilisation

- utiliser des identifiants et références, pas des secrets ;
- dater et attribuer chaque décision ;
- conserver les preuves sources dans un emplacement protégé ;
- réviser périodiquement les entrées ouvertes ;
- ne jamais publier de données personnelles dans une pull request publique.

Les fichiers présents dans le dépôt sont des modèles vides. Les registres réels de production doivent rester dans un système à accès contrôlé.
