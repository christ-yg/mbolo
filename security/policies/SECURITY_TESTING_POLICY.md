# Lot 45 — Tests de sécurité

La stratégie associe tests unitaires d’autorisation, tests d’intégration, E2E public et authentifié, SAST, audit de dépendances, scans d’images et contrôle de configuration. Un test ne doit pas utiliser de données personnelles réelles. Les échecs bloquants sont corrigés avant fusion ou font l’objet d’une exception de risque approuvée.
