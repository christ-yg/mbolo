# Lot 43 — Cryptographie et secrets

TLS protège les communications. Les mots de passe sont traités par les mécanismes robustes du framework. Les secrets proviennent de variables d’environnement ou d’un gestionnaire dédié, jamais du code ou des images. Les sauvegardes sensibles sont chiffrées. Toute clé compromise est renouvelée et son utilisation résiduelle recherchée.
