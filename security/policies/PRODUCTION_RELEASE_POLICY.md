# Lot 49 — Autorisation de mise en production

Une version est publiable lorsque la branche est propre, les migrations sont contrôlées, les sauvegardes et le retour arrière sont prêts, les tests sont verts, les scans ne signalent aucun risque bloquant, les services sont healthy et les smoke tests réussissent. L’autorisation finale reste une décision humaine traçable.
