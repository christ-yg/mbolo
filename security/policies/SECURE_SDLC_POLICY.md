# Lot 41 — Développement sécurisé

Chaque changement passe par une branche dédiée, une revue, des tests et les contrôles CI. Les secrets restent hors du dépôt. Les actions CI sont épinglées sur des SHA immuables. Les dépendances sont verrouillées. Les changements d’authentification, d’autorisation, de paiement, de données privées ou d’infrastructure exigent des tests de sécurité ciblés.
