# Lot 34 — Réponse aux incidents

1. Détecter et horodater l’événement.
2. Qualifier la gravité et préserver les preuves.
3. Contenir sans détruire les traces.
4. Éradiquer la cause et restaurer depuis une source saine.
5. Informer les responsables et, si nécessaire, les personnes concernées.
6. Produire un retour d’expérience et suivre les actions correctives.

Les secrets compromis sont révoqués immédiatement. Aucun jeton ou donnée personnelle ne doit apparaître dans les tickets publics.
