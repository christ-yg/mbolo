# Lot 38 — Classification des données

- **Publique** : pages institutionnelles et documentation publique.
- **Interne** : procédures et métadonnées techniques non sensibles.
- **Confidentielle** : profils, coordonnées, événements de sécurité.
- **Très sensible** : secrets, preuves d’identité, médias privés, sauvegardes.

La collecte est minimisée. Le niveau le plus élevé applicable détermine le stockage, l’accès, le partage et la suppression.
