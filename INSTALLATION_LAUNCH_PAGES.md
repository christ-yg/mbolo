# Mbolo — Lot 04 Pages publiques de lancement

Ce lot ajoute trois pages publiques complètes sans service payant :

- `/about` — À propos de Mbolo ;
- `/how-it-works` — Comment fonctionne le parcours ;
- `/help` — Centre d'aide et FAQ.

Le routeur et le pied de page sont remplacés par des fichiers complets basés
sur la version de `main` vérifiée avant la préparation du lot.

## Validation

Depuis `~/projects/mbolo` :

```bash
cd frontend
npm run check
cd ..
```

Puis reconstruire la préproduction locale et vérifier les trois URL dans le
navigateur.
